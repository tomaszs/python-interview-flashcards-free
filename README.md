### Sample questions

- Explain the GIL in Python 3.12 and its implications for multi-threaded applications. How has it evolved, and what are common strategies to work around it?
- Describe the new features and improvements introduced in Python 3.12. Focus on those relevant to performance or developer experience.
- How do you effectively use `asyncio` for building high-performance network services in Python 3.12? Discuss common patterns and potential pitfalls.
- What are type hints in Python, and how do they contribute to maintainable and robust codebases, especially in large projects? Provide examples of advanced typing features.
- Differentiate between `mypy` and `pyright`. When would you choose one over the other for static type checking in a Python project?
- Explain the concept of a `Protocol` in Python typing. Provide a practical example where it significantly improves code clarity or flexibility.
- How do you handle dependency management and virtual environments in a large Python project? Compare `pip-tools`, `Poetry`, and `Rye`.
- Discuss the trade-offs between using `dataclasses`, `NamedTuple`, and custom classes for defining data structures. When would you choose each?
- Implement a custom context manager using both a class and a generator function (`@contextlib.contextmanager`). Explain the differences.
- Describe the principles of Object-Oriented Programming (OOP) in Python. How does Python's approach to OOP differ from strictly class-based languages?
- Explain the Method Resolution Order (MRO) in Python. How does it work, and how can you inspect it?
- What are metaclasses in Python? Provide a concrete example of when you might use a metaclass in a production system.
